# Supervised-Learning-Challenge
This repository contains my submission for the Module 20 Challenge due on 3/18. All of the work present has been created by myself, Molly Pfefferkorn. My instructor, Dr. Carl Arrington, provided troubleshooting feedback during the designated office hours of this class. Data for this dataset was generated by edX Boot Camps LLC, and is intended for educational purposes only.
-----
In this challenge, I applied logistic regression to evaluate credit risk using a dataset of historical lending activity from a peer-to-peer lending platform.  After loading the lending_data.csv file into a Pandas DataFrame in credit_risk_classification.ipynb, I prepared the data by separating the loan_status column as the target variable (y) and the remaining features as the input data (X). The dataset was then split into training and testing sets using train_test_split.

I built a logistic regression model using the training data and used it to predict loan outcomes on the test set. The model’s performance was assessed through a confusion matrix and a classification report, which included key evaluation metrics such as accuracy, precision, and recall. These results provided insight into how well the model could distinguish between healthy loans (label 0) and high-risk loans (label 1).
Finally, I documented the analysis in a comprehensive Credit Risk Classification Model Analysis.md report, outlining the purpose of the project, the model’s performance metrics, and an interpretation of the results. I discussed whether the model was reliable enough for deployment in a real-world financial setting and justified my recommendation based on its ability to accurately identify high-risk loans.
